# 🐉 Meu Dia Saiyan — PWA

Quadro de atividades diárias temático Dragon Ball Super, instalável como app no Android/tablet.

## 📱 Como instalar no tablet

1. Siga os passos abaixo para publicar no GitHub Pages
2. Abra o link gerado no **Chrome** do tablet
3. O Chrome mostrará um banner **"Adicionar à tela inicial"** — toque nele
4. O ícone aparece na tela do tablet igual a um app nativo!

---

## 🚀 Como publicar no GitHub Pages (passo a passo)

### 1. Criar conta no GitHub
- Acesse [github.com](https://github.com) e crie uma conta gratuita

### 2. Criar repositório
- Clique em **"New repository"** (botão verde)
- Nome: `quadro-saiyan`
- Deixe como **Public**
- Clique em **"Create repository"**

### 3. Fazer upload dos arquivos
- Na página do repositório, clique em **"uploading an existing file"**
- Arraste todos os arquivos e a pasta `icons/` para a área de upload
- Clique em **"Commit changes"**

### 4. Ativar GitHub Pages
- Vá em **Settings** (na barra do repositório)
- No menu lateral, clique em **Pages**
- Em "Source", selecione **Deploy from a branch**
- Branch: **main** | Folder: **/ (root)**
- Clique em **Save**

### 5. Acessar o app
- Após ~1 minuto, o link estará disponível:
  ```
  https://SEU_USUARIO.github.io/quadro-saiyan/
  ```
- Abra esse link no Chrome do tablet para instalar!

## ✨ Funcionalidades

- ✅ **Checklist interativo** por período (manhã / tarde)
- 📅 **Navegação por dias da semana** com aulas específicas por dia
- 🔥 **Streak de dias consecutivos** (como o Duolingo)
- 📊 **Histórico completo** com barra de progresso por dia
- 🏆 **Sistema de conquistas** (8 conquistas para desbloquear)
- ⚡ **Sistema de Ki** e fases Saiyan (Humano → Ultra Instinto)
- 💾 **Salva progresso** no dispositivo (funciona offline)
- 📱 **Tela de splash** animada ao abrir
- 📳 **Vibração** ao marcar tarefas

## 🛠️ Atualizar o app

Qualquer alteração feita nos arquivos do GitHub é publicada automaticamente em ~1 minuto. O app no tablet atualiza sozinho na próxima vez que abrir com internet.
